# Development Prerequisites

## Document status

**Status:** Draft

This document records the tools required to develop, test, build, and package
PCF controls in this repository.

The documented versions represent the versions verified in the initial local
development environment. They do not yet represent minimum supported versions
for every contributor.

## 1. Verified environment

The initial development environment uses:

- macOS
- Apple Silicon architecture
- Visual Studio Code
- Z shell
- Git
- Node.js
- npm
- Microsoft Power Platform CLI

- Reverting changes

Verify the installed version:

```bash
git --version
```

The initially verified version is:

```text
git version 2.50.1 (Apple Git-155)
```

## 4. Node.js

Node.js runs the JavaScript-based development and build tooling used by PCF.

Verify the installed version:

```bash
node --version
```

The initially verified version is:

```text
v24.19.0
```

Node.js 24 is an LTS release.

Compatibility with the dependencies generated by the official PCF React
template must still be verified through an actual dependency installation and
production build.

The repository should not yet define Node.js 24 as its minimum or mandatory
version.

## 5. npm

npm manages the JavaScript and TypeScript dependencies used by PCF projects.

npm will be used to:

- Install dependencies
- Restore dependencies from the lock file
- Run local builds
- Start the PCF test harness
- Run linting
- Run unit tests
- Produce production builds

Verify the installed version:

```bash
npm --version
```

The initially verified version is:

```text
11.17.0
```

## 6. Microsoft Power Platform CLI

Microsoft Power Platform CLI provides commands for creating, building,
deploying, and packaging PCF projects.

Verify that the CLI is available:

```bash
pac help
```

Verify that the PCF command group is available:

```bash
pac pcf help
```

Inspect the PCF project initialization command:

```bash
pac pcf init help
```

The initially verified PAC CLI version is:

```text
2.10.1
```

Running the following command prints the version banner but also returns a
command-parsing error with the verified PAC CLI version:

```bash
pac --version
```

For this reason, `pac help` and `pac pcf help` are used as the functional
verification commands.

Authentication with a Power Platform environment is not required for local
project initialization or the first local build.

Authentication will be configured only when the first control is ready for
testing in a Dataverse environment.

## 8. .NET SDK

The .NET SDK will be used to build the Dataverse solution project that
packages one or more PCF controls.

Verify the active SDK:

```bash
dotnet --version
```

The initially verified SDK version is:

```text
10.0.302
```

Display detailed installation information:

```bash
dotnet --info
```

The initially verified .NET environment is:

```text
.NET SDK:       10.0.302
MSBuild:        18.6.11
.NET Host:      10.0.10
Architecture:   ARM64
Runtime ID:     osx-arm64
```

The installation includes:

- Microsoft.NETCore.App 10.0.10
- Microsoft.AspNetCore.App 10.0.10

No optional .NET workloads are currently installed.

No additional workload will be installed unless a later build process
demonstrates that it is required.

No `global.json` file currently pins the repository to a specific .NET SDK
version.

The repository should not define .NET 10 as its mandatory version until the
first Dataverse solution project has been created and built successfully.

The .NET SDK is not required to initialize the first PCF project. It will be
used when the first Dataverse solution package is built.
